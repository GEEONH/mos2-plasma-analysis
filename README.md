# MoS2 플라즈마 처리 데이터 정량 분석

졸업연구(캡스톤디자인 2025)에서 측정한 라만/PL 스펙트럼을
파이썬으로 정량화하고 공정 조건을 분석한 개인 프로젝트입니다.
원 데이터 사용은 지도교수 승인을 받았습니다.

## 배경

H2 플라즈마로 MoS2의 2H→1T 상전이를 유도하는 연구였습니다.
라만에서 구조 변화 신호는 나왔지만 4-point probe는 절연 특성을 보였고,
원인은 "결함 때문으로 추정된다"는 정성적 서술로 남았습니다.

이 프로젝트는 그 판단을 숫자로 바꾸는 것을 목표로 했습니다.

## 방법

- 전처리: ALS 베이스라인 보정 → Savitzky-Golay 스무딩 → 정규화
- 기판 Si 520.7 cm-1 피크를 내부 표준으로 사용 (측정 조건 차이 보정, ±5% 안정)
- 358~432 cm-1 구간 3성분 Lorentzian 피팅 (E2g+, E2g-, A1g)
- 지표 정의
  - E2g_split : 면내 대칭성 붕괴 = 구조 변형
  - PL_rel    : pristine 대비 PL 강도 = 결함 밀도
  - A1g_cen   : A1g 피크 위치 = 누적 손상

## 데이터

| 파일 | 시료 | 조건 |
|---|---|---|
| metrics.csv | 기계적 박리 MoS2 / SiO2 | 파워 0–70 W, 10초 고정 |
| cvd_metrics.csv | CVD MoS2 / Al2O3 | 파워 0–90 W, 10초 고정 |
| time_a_metrics.csv | MoS2 / SiO2 | 20 W, 0–140초 |
| time_b_metrics.csv | MoS2 / Al2O3 | 0–90초 |

## 결과

**1. 결함과 구조 변형의 문턱이 분리된다**
PL은 10 W부터 급감하지만 E2g 분열은 40 W까지 변화가 없다.
단일 원인이라면 함께 움직여야 하므로 최소 두 개의 과정이 존재한다.

**2. 시료 형태가 문턱을 두 배 바꾼다**
시그모이드 피팅 + 부트스트랩 결과 박리 시료 40.5 W, CVD 시료 72.7 W.

**3. 저파워 PL 거동이 시료에 따라 반대**
10 W에서 박리 시료는 PL이 65% 감소, CVD 시료는 44% 증가했다.
CVD 시료의 높은 S 결손이 수소로 패시베이션되기 때문으로 해석되며,
저파워 영역이 상전이가 아닌 결함 화학에 지배됨을 시사한다.

**4. 구조 변형은 포화하고 손상은 누적된다**
20 W 시간 시리즈에서 E2g 분열은 20초에 포화했지만
A1g 위치는 402.5 → 410.0 cm-1로 끝까지 이동했다.

## 한계

1T 상전이를 직접 증명하지는 못했습니다.

직접 증거인 J1·J2·J3 모드는 대부분의 조건에서 검출되지 않았습니다.
반복 측정 평균화를 시도했으나 잔차가 √n에 따라 감소하지 않아,
랜덤 노이즈가 아닌 계통적 배경이 한계임을 확인했습니다.
3σ 검출 한계는 A1g 대비 약 2%입니다.

E2g_split은 간접 지표이며 1T 도메인 외에
수소 인터칼레이션이나 점결함으로도 설명될 수 있습니다.
